# Visual Assets for Landing Page

## Required Assets

These assets should be created manually and placed in this directory:

1. **pipeline.webp** — Simplified architecture/pipeline diagram (email → extraction → search → matching → draft)
   - Recommended tool: Excalidraw, Figma, or Canva
   - Dimensions: 1200x627px
   - Style: Clean, minimal, blue color scheme

2. **card-green.webp** — Teams notification screenshot (high confidence)
   - Capture or recreate a Teams Adaptive Card showing a high-confidence quote notification
   - Dimensions: 1080x1080px or 1200x627px

3. **card-amber.webp** — Teams notification screenshot (medium confidence)
   - Multi-proposal notification card
   - Same dimensions

4. **card-red.webp** — Teams notification screenshot (low confidence)
   - Escalation notification card
   - Same dimensions

## Notes

- Use WebP format for optimal loading speed
- Optimize images: target < 100KB each
- The current landing page uses HTML/CSS-based visual elements instead of image files
- Add actual screenshots when available for more authentic proof
